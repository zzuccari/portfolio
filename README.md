# Zeno Zuccari — Personal Website

Source for [zzuccari.github.io/portfolio](https://zzuccari.github.io/portfolio), built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Editing content

- `_config.yml` — site-wide settings and sidebar author info (name, bio, contacts)
- `_pages/about.md` — main page content
- `_data/navigation.yml` — top navigation menu (sections are commented out until there's content for them)
